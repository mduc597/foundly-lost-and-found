# US-05 — Xem chi tiết bài đăng

**Sprint:** 1 · **Ưu tiên:** P0  
**Mục tiêu:** Mở nội dung một bài gồm tên, mô tả, thời gian mất/nhặt, thời gian đăng, địa điểm và trạng thái.

## Code tương ứng trong `demo/`
- Frontend: `web/src/features/US05_ReportDetail.jsx`
- Backend: `api/Controllers/ReportsReadController.cs` (Detail)

## Tiêu chí nghiệm thu đề xuất
- Nhấn “Xem chi tiết” hiển thị đầy đủ nội dung.
- Trạng thái được hiển thị rõ.
- Chủ bài có thể sửa/xóa từ giao diện chi tiết (CRUD bổ trợ).
